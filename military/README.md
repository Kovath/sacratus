# Sacratan Military

This README is a human-facing navigation page for lore concerning the **Sacratan Military**: the conventional human armed forces of the Sacratus system. It does not include the Palatinae, House Falkenrath, Sororitas, Skitarii, or the civilian administration.

Canonical details live in the linked reference files.

- [`overview.md`](overview.md) — high-level identity, scope, and strategic role.
- [`history.md`](history.md) — development from pre-Breaking Imperial forces through the Long Vigil and Reintegration.
- [`organization.md`](organization.md) — the Limitanei/Comitatenses distinction, institutional boundaries, and currently established organizational facts.

The subject remains comparatively underdeveloped. No separate `timeline.md`, `culture.md`, or `figures/` directory exists yet because the current canon does not justify them.
