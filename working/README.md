# Working material

This directory is non-canonical scratch space for ongoing Sacratus development.

AI may use it to maintain material such as:

- open questions;
- provisional alternatives;
- rejected ideas worth remembering;
- continuity concerns;
- summaries of active discussions;
- possible future developments that have not been accepted as canon.

Nothing in `working/` overrides merged top-level canon. Persistence here does not imply acceptance.

When a working idea is accepted, promote the relevant result into the appropriate top-level canon document through a reviewed pull request rather than treating the working note itself as canon.
