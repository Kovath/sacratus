# House Falkenrath

This README is a human-facing navigation page for lore concerning **House Falkenrath**, the Questor Mechanicus Knight branch trapped within Sacratus during the Long Vigil. Canonical details live in the linked reference files.

- [`overview.md`](overview.md) — high-level identity, scale, role, and present position.
- [`history.md`](history.md) — causal history from the pre-Breaking detachment through Reintegration.
- [`organization.md`](organization.md) — the stranded branch, its supporting household, operational strength, and institutional boundaries.

No dedicated `figures/` directory exists yet because no individual Falkenrath pilot has been developed enough to require a canonical record.
